# AIMRA: AI-Integrated Mineral Regulatory Architecture Dataset and Reproducibility Package

This repository provides the reproducibility materials for the manuscript:

**AI-Driven Decision Intelligence Architecture for Mineral Resource Management under Regulatory Constraints: The AIMRA Framework**

The package supports the African AI-Integrated Mineral Regulatory Architecture (AIMRA), a four-layer decision-intelligence framework for embedding artificial intelligence within mineral resource management systems under regulatory constraint.

## What this repository contains

- Corpus-access register and source-access notes
- Annotation codebook for AIMRA governance indicators
- Metric input data for South Africa, Agbabu, and global tar sand analogues
- Statutory rule-encoding examples for AIMRA Layer 3
- Scripts for computing the bounded governance-performance function
- Scripts for nonlinear geometric-mean robustness checks
- Comprehensive Reconciliation Report (auditing manuscript/supplementary metrics)
- Supplementary annotation/data-access protocol
- Graphical abstract for the AIMRA framework

## Important scope note

This is a **Stage 1 design-science reproducibility package**. It should not be interpreted as a completed field-deployment dataset. Some values are derived from public institutional reports, structured estimates, uncertainty ranges, and cross-sector analogue assumptions documented in the workbook and manuscript.

Restricted institutional records required for Stage 2 field validation are not redistributed. Instead, the repository documents the proposed access routes, calibration procedures, and uncertainty-handling strategy.

## Reproducing the main calculations

From the repository root, run:

```bash
python scripts/compute_aimra_g.py
python scripts/robustness_geometric_mean.py
```

The recalculated outputs will be written to the `outputs/` folder.

## Manuscript and Supplementary Reconciliation

A comprehensive **Reconciliation Report** (`docs/reconciliation_report.md`) has been generated by strictly auditing the text and tables of the manuscript and supplementary materials against the computational truth generated by these scripts. 

Please consult the reconciliation report for the verified list of corrections (including mathematical/rounding discrepancies in South Africa and Agbabu sensitivity configurations, and a corrected Equation 4 notation). **Note:** To prevent the propagation of mathematically inaccurate baseline or improvement metrics, the manuscript itself and the supplementary materials document have been deliberately excluded from this repository until the flagged corrections are applied.

## AIMRA indicators

The composite governance-performance function uses five normalised indicators:

| Indicator | Meaning |
|---|---|
| `RLI_norm` | Normalised regulatory latency / decision-cycle time score |
| `CDR` | Compliance detection rate / operational visibility score |
| `RLR_norm` | Normalised resource value-loss score |
| `RCS` | Regulatory consistency / decision stability score |
| `AAI` | Auditability and accountability score |

The equal-weight Stage 1 composite score is:

```text
G = 0.20 × (RLI_norm + CDR + RLR_norm + RCS + AAI)
```

The nonlinear robustness score is computed as the geometric mean of the five normalised indicators.
