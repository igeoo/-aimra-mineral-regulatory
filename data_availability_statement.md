# Data Availability Statement

The data and reproducibility materials supporting this study are provided in this repository and may be archived permanently on Zenodo. The repository contains the corpus-access workbook, annotation codebook, source register, metric input data, statutory rule-encoding examples, and scripts used to compute the AIMRA composite governance-performance function and nonlinear robustness checks.

The dataset comprises publicly available institutional reports, structured estimates, documented cross-sector analogues, and reproducible calculations. Restricted institutional records required for Stage 2 field validation are not redistributed. Instead, the repository documents proposed access routes, calibration procedures, uncertainty ranges, and quality-control procedures.
